## Task 3 — A trait per resource kind

`src/sync.rs`. Three traits so a new agent must answer each question rather than
inherit a default it never considered:

```rust
trait SkillTarget      { fn skills(&self, cx: &Cx) -> Result<Vec<Action>>; }
trait SubagentTarget   { fn subagents(&self, cx: &Cx) -> Result<Vec<Action>>; }
trait InstructionTarget{ fn instructions(&self, cx: &Cx) -> Result<Vec<Action>>; }
```

Implemented by two zero-sized types, `Claude` and `Opencode`; `Agent` maps to
`&dyn`. `Cx` bundles `project`, `layers`, `source`.

**Skills resolve to the same destination for both agents.** opencode *reads*
`~/.claude/skills` but nothing else *writes* it — so `--agent opencode` alone
must still install there, or the pipeline's two central skills exist nowhere.
`sync` dedupes by destination so two selected agents do the work once.

**Verify:** `cargo test --workspace`

## Task 4 — Render subagents for opencode

Split the source frontmatter, map it, re-emit. Per the context pack:
`tools:` is a **comma-separated scalar**, `serde_yaml` 0.9 emits **block style
only**, and it has **no comment API** — so the `# generated by bevel — requires
opencode v2 or newer` line is spliced by hand, the way `Spec::save` builds its
fence (`src/spec.rs:175-180`).

`name:` is dropped (opencode takes the id from the filename), `model:` is
dropped, `mode: subagent` is added, `tools:` becomes a `permissions` allow-list
**closed by a terminal `{action: "*", resource: "*", effect: deny}`**.

Fills: `opencode_subagents_land_where_opencode_reads_them`,
`a_subagents_tool_set_survives_translation_into_opencode_permissions`,
`the_claude_only_model_shorthand_is_dropped_rather_than_translated`.

**Verify:** `cargo test --workspace`

## Task 5 — `AGENTS.md` becomes the body, `CLAUDE.md` the pointer

New `Action::Moved`, because the spec requires a move be reported as a move.

The classification, since `CLAUDE.md` carries no marker (`write_if_absent`,
`src/sync.rs:151`):

| `AGENTS.md` | `CLAUDE.md` | outcome |
|---|---|---|
| exists, ours | any | update/skip as usual |
| exists, not ours | any | **skip the whole resource**, reported |
| absent | absent | write body |
| absent | byte-identical to `CLAUDE_MD` | write body, replace with pointer |
| absent | anything else | **move whole** to `AGENTS.md`, leave pointer |

Fills: `the_project_body_lives_in_agents_md_with_claude_md_pointing_at_it`,
`a_hand_edited_claude_md_is_moved_whole_and_never_silently_discarded`.

**Verify:** `cargo test --workspace`

## Risks

- **`agents/` vs `agent/`.** Plural. Wrong here = installed where nothing reads,
  which looks identical to success.
- **The opencode v2 action spellings** (`read`/`grep`/`glob`/`bash`/`write`/
  `webfetch`) are inferred from our tool names. The spec makes the *shape* the
  contract and the spellings not; if they cannot be confirmed, that goes in
  `notes.md` rather than being asserted as fact.
- **Tests must never touch the real `$HOME`.** `setup()` builds `Layers` against
  a tempdir; the opencode tree needs the same treatment or a test run edits the
  developer's own agent config.
